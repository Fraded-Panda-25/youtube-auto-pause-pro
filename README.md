# 🚀 YouTube Auto Pause Chrome Extension

A simple and powerful Chrome Extension that automatically pauses YouTube videos when you switch tabs and resumes playback when you return.

---

## 🎯 Problem

While watching YouTube, videos continue playing even when you switch tabs.  
This leads to:
- ⏳ Time waste  
- 🔇 Missing important content  
- 😵 Distractions  

---

## 💡 Solution

This extension:
- ⛔ Automatically pauses the video when the tab becomes inactive  
- ▶️ Resumes the video when you return to the tab  
- ⚡ Works instantly without any setup
